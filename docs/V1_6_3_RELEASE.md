# v1.6.3 舰艇与海军武器验收

v1.6.3 按批准边界完成海军装备闭环：

- 舰级与具体舰艇边界；
- 舰艇动力及平台关系；
- 舰炮与弹药；
- 导弹、鱼雷及武装关系；
- 雷达、声呐及传感器关系；
- 服役组织与时间关系；
- 多配置技术声明隔离；
- 独立海军 Godot Runtime Bundle/Lock。

锁定 Runtime profile 为 `data/curated/destory/naval_build_profile.json`，包含 20 个实体、24 个配置、67 条技术声明、28 个来源引用和 17 条独立关系断言。其 Bundle/Lock 契约和真实 Godot 4.7.1 加载由自动测试及领域运行矩阵共同验证。

关系不能仅凭口径相同推断；舰炮—弹药、平台—鱼雷和平台—声呐关系均保存独立来源。
