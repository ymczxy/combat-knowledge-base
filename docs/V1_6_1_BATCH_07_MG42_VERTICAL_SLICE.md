# v1.6.1 Batch 07 — MG42 vertical slice

## Scope

This batch adds a source-checked MG42 entity and links it to the existing `8 x 57 IS` canonical cartridge entity created in Batch 04.

## Evidence boundary

- Imperial War Museums object FIR 8042 supports the model identity and the specific object's 1220 mm length, 370 mm height, 145 mm width, 11.85 kg weight and 1944 production context.
- Royal Armouries supports the general-purpose machine-gun classification and late-Second-World-War service context.
- National Army Museum supports the preserved `7.92 mm` calibre wording and the published 1,200–1,500 rounds-per-minute range.
- C.I.P. remains the canonical naming authority for the existing `8 x 57 IS` cartridge entity.

Object measurements are not generalized beyond the cited museum object. The rate-of-fire statement retains its museum-description scope.

## Safety and gameplay boundary

The batch contains no loading recipes, propellant charges, primer specifications, manufacturing tolerances, manufacturing guidance, attack procedures or gameplay balance values.
