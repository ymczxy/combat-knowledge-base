# 来源汇聚策略

CKB 不依赖单一百科，而是让不同来源承担不同职责。

| 来源 | 主要用途 |
|---|---|
| Wikidata | 实体 ID、名称、国家、年代、外部 ID |
| Wikipedia | 发现型号谱系和原始引用线索 |
| Wikimedia Commons | 图片候选和媒体元数据 |
| 博物馆与档案馆 | 冷兵器、历史实物和馆藏记录 |
| 政府与军方公开资料 | 公开服役信息、系统构成和参数 |
| 制造商公开资料 | 产品型号和公开系统描述 |
| 专业专题站点 | 坦克、舰炮、导弹、飞机等领域补充 |
| GitHub 开源数据 | CSV/JSON、别名表、解析器和分类参考 |
| 学术论文和技术报告 | 术语、历史演进、材料作用与交叉验证 |

## 来源优先级

- S：官方手册、档案、军方公开资料；
- A：学术、博物馆、权威研究机构和制造商；
- B：Wikidata、Wikipedia、成熟专题站；
- C：社区 Wiki、论坛和爱好者数据库，仅作线索；
- D：无来源聚合内容，原则上不入主库。

## 采集原则

```text
来源发现 → 来源登记 → 原始声明 → 实体解析 → 标准化 → 冲突记录 → 审核 → 主库
```

AI 只能生成候选，不可自行批准关键事实、许可状态和争议合并。
