# v1.6.2 Batch 02 — F-16 / F100 vertical slice

This batch adds a jet-era aviation chain:

- `ckb:platform:air:f_16c_fighting_falcon`
- `ckb:component:engine:pratt_whitney_f100_pw_220`
- an explicit, configuration-scoped `uses_engine` assertion

The F-16 fact sheet documents multiple engine families. The relation therefore remains scoped to the F100 family and does not imply that every F-16 variant uses the F100-PW-220. The museum record supplies the engine display identity and family context.
