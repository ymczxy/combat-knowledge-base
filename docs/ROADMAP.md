# 全量路线图

本项目按并行工作流推进，不以最小闭环为目标。

## Track A 分类与模型

知识域、武器、平台、弹药、材料、作用、时代、国家、现代体验和 Godot 派生模型。

## Track B 来源适配

Wikidata、MediaWiki、Commons、博物馆 API、官方页面/PDF 元数据、GitHub CSV/JSON、人工 CSV 和专题站适配器。

## Track C 历史装备

冷兵器、古代火器、工业时代、一战、两战之间、二战。

## Track D 冷战与现代

单兵、地面、航空、海军、导弹、精确打击、无人系统、传感器、火控和电子战。

## Track E 《destory》接入

武器、弹药、材料响应、爆炸、热、烟气、压力、音画体验、AI 和游戏内百科。

## Track F 质量与构建

Schema、语义校验、去重、冲突、SQLite、Markdown、Godot Bundle、CI 和完整度面板。

## 版本阶段

- 1.x：工程、分类和目录基线；
- 2.x：主要来源适配与规模化采集；
- 3.x：冷兵器至二战主体；
- 4.x：冷战与现代主体及体验配置；
- 5.x：《destory》深度接入；
- 6.x：长尾补全、审校和长期维护。

## “全部完成”的定义

- 目标领域都有稳定分类；
- 主要来源均有适配或人工导入流程；
- 目录实体至少达到 C 级；
- 核心实体达到 A/B 级；
- 核心现代装备具备体验配置；
- Godot 能稳定消费版本锁定子集；
- 构建、校验和冲突检测自动化。
