# 现代装备“体验可感知”模型

百科参数不会自动变成可信体验。CKB 用九个维度描述玩家真正能察觉的差异。

## 1. 声学 Acoustic

- 发射瞬态、低频冲击、高频机械声；
- 连发节奏、尾音、远距传播；
- 室内反射和封闭空间增幅；
- 发射者、旁观者、目标侧的差异。

## 2. 视觉 Visual

- 发射焰、烟羽、曳光、热浪；
- 扬尘、水面扰动、碎片和二次燃烧；
- 夜间暴露程度和远距离可见性。

## 3. 冲击与镜头 Impulse

- 后坐脉冲、相机位移和旋转；
- 恢复时间、旁侧冲击、爆压、耳鸣；
- 建筑内部和室外的差异。

## 4. 操控 Handling

- 惯性、转向、举起、稳定、装填；
- 狭窄空间惩罚、姿态差异和疲劳；
- 单人、班组、车载和固定安装的差异。

## 5. 环境 Environmental

- 烟尘、热、压力、气体和可见度；
- 地面、水面、植被、室内空气和设备影响。

## 6. 目标反应 Target Response

- 穿孔、凹陷、裂纹、剥落、破片；
- 燃烧、位移、功能失效、泄漏和二次事故。

## 7. 传感器与信息 Sensor UX

- 探测、跟踪、锁定、丢锁和告警；
- 热像、雷达、数据链、电子干扰和信息负荷。

## 8. 操作员负荷 Crew Burden

- 人数、协同、弹药搬运、视野、噪声、热和震动；
- 重复操作疲劳与恢复节奏。

## 9. 故障与退化 Failure Cues

- 声音异常、温升、烟雾变化、精度恶化；
- 传感器噪点、电源波动、液压迟缓和结构损伤。

## 四种观察位置

同一事件至少考虑：发射者、同室友军、目标附近、远距离观察者。体验配置是游戏派生值，不等同于实测数据。
