# v1.6.1 Batch 04 — Karabiner 98k vertical slice

## Scope

This batch adds a source-checked Karabiner 98k entity, an 8 x 57 IS cartridge entity, and an independent `uses_ammunition` assertion.

## Evidence boundary

The weapon profile uses National Army Museum and Imperial War Museums catalogue records for public identification, action, dimensions, capacity, adoption and service context. The cartridge profile uses those museum records for compatibility and the C.I.P. public homologation record for the modern `8 x 57 IS` rimless-cartridge designation.

Museum catalogue dimensions are object-qualified. The National Army Museum effective-range wording is retained as descriptive text rather than converted into a generalized performance value.

## Safety boundary

The batch excludes loading recipes, propellant charges, primer specifications, manufacturing tolerances, attack instructions and gameplay balance values.
