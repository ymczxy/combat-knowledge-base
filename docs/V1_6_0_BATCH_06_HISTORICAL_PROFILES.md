# v1.6.0 Batch 06：历史装甲车辆技术与体验档案

## 目标

Batch 06 验证 Batch 05 建立的声明式技术模型能否覆盖现代主战坦克以外的车辆。首批历史样本包括：

- M4 Sherman 家族；
- T-34 Model 1940 / T-34/76；
- Panther 家族；
- 59式中型坦克。

这些样本跨越二战与早期冷战，并覆盖不同乘员数量、质量、机动、火炮、悬挂与维护理念。

## 家族与改型边界

M4 Sherman 不使用单一参数代表整个家族。Batch 06 分别保存 Tank Museum 馆藏 M4A2E8 和 M4A4 Sherman VC Firefly 的乘员、质量、速度和主炮声明。两组数据必须保留 `configuration` 限定，不能求平均或互相覆盖。

T-34 档案对应早期 L-11 76.2毫米炮的 T-34/76 参考配置。Panther 档案对应博物馆的 Sd.Kfz.171 Panther 家族参考车辆。59式档案只描述基础型号，不混入59-I、59-II、59D或出口改型参数。

## 来源与审核

- M4 Sherman：美国陆军历史资料与 The Tank Museum；
- T-34/76：Wikipedia 初始记录与 The Tank Museum 馆藏资料；
- Panther：Wikipedia 初始记录与 The Tank Museum 馆藏资料；
- 59式：中国国防部公开资料与中国机械工程数字博物馆资料。

T-34与Panther在本批增加第二来源并提升为 `source_checked`。这仍不等同于 `cross_checked`，也不表示所有生产批次和战场改型都已完成审核。

## 体验派生重点

- M4：强调家族改型差异、适中质量、人工装填和不同主炮带来的乘员节奏差异；
- T-34：强调较低质量、较高速度、倾斜外形和较少系统辅助；
- Panther：强调更高质量、五人乘员、宽履带与复杂重叠负重轮的视觉和维护存在感；
- 59式：强调四人乘员、人工装填、直接机械反馈，以及资料明确描述的结构简单、可靠和便于维护。

所有维度仍是公开技术事实的可解释派生值，并保持 `not_game_balance: true`。它们不直接决定游戏内速度、伤害、装甲值或经济成本。

## 质量指标

Batch 06 新增31条技术声明：

- M4 Sherman：9条；
- T-34 Model 1940：6条；
- Panther：7条；
- 59式：9条。

批次门禁要求每个实体至少两个来源、至少六条技术声明，并具备合法的派生体验档案。回归测试额外检查 M4 两个配置同时存在、Panther 分类被具体化，以及本批四个档案都没有退化为游戏平衡字段。
