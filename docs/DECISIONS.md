# 架构决策记录

## ADR-001 独立仓库

**状态：批准。** CKB 独立于 `destory`，游戏只消费锁定版本的裁剪包。

## ADR-002 许可证暂不阻塞研发

**状态：暂行。** 当前优先研究、分类和数据工程。仍保留来源 URL、获取日期、来源 ID、媒体来源和 `rights_status`，否则未来无法追溯。

## ADR-003 不采用最小闭环优先

**状态：批准。** 项目从一开始建设完整分类和全量目录，并行推进六条工作流：

1. 分类与 Schema；
2. 来源适配；
3. 冷兵器至二战；
4. 冷战与现代；
5. 现代体验模型；
6. Godot 与《destory》接入。

## ADR-004 现代装备达到体验可感知层

**状态：批准。** 每个核心现代装备应能描述：玩家看到、听到、身体感受到、如何操控、环境如何改变、传感器如何反馈、目标如何响应、失效前有什么征兆。

## ADR-005 安全边界

允许详细整理公开参数、系统组成和可感知效果；不整理现实制造步骤、危险配方、绕过防御步骤、现实目标攻击规划或非公开漏洞。
